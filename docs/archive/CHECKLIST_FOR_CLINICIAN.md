**所需内容：**

- 患者年龄、性别
- 主诉症状 (如："活动后胸闷"、"胸痛 3 天"等)
- 危险因素 (高血压、糖尿病、吸烟史等)

#### b) DSA 诊断结论 (核心部分)

**格式要求：** 每个有病变的血管段需要包含：
1. **位置** (如："右冠近段" / "前降支中段")
2. **狭窄程度** (百分比，如："75%" / "90%")
3. **血管名称** (SYNTAX 命名，如："RCA_1" / "LAD_6")

**示例：**
```
右冠近段 (RCA_1): 重度狭窄 75%，钙化斑块
前降支中段 (LAD_6): 中度狭窄 60%，软斑块
回旋支近段 (LCX_11): 轻度狭窄 30%
左主干 (LM_5): 未见明显狭窄  ← 阴性发现也要标注
```

#### c) 关键要求：阴性发现也要标注 ⚠️

**重要：** 根据上次会议，即使某个血管段"未见狭窄"，也需要明确写出来。

**原因：** 
- 这是临床报告的标准格式
- AI 模型需要学习区分"未检查"和"检查了但正常"
- 评估 rubric 会对"遗漏阴性段"进行扣分

**示例完整报告：**
```
诊断结论：
- 右冠近段 (RCA_1): 重度狭窄 75%
- 右冠中段 (RCA_2): 未见明显狭窄  ✅
- 前降支近段 (LAD_5): 未见明显狭窄  ✅
- 前降支中段 (LAD_6): 中度狭窄 60%
- 前降支远段 (LAD_7): 未见明显狭窄  ✅
- 回旋支 (LCX_11): 轻度狭窄 30%
```

## ❓ 常见问题

### Q1: 为什么阴性发现也要标注？
**A:** 临床报告的标准做法。AI 需要学会区分"未检查"和"检查了但正常"。类比：体检报告不会只写"肝功能异常"，会写"肝功能正常，肾功能正常，血脂异常"。

### Q2: SYNTAX 命名太复杂，能用中文吗？
**A:** 可以！您用中文描述 (如"右冠近段")，我们会转换为 SYNTAX 编号 (RCA_1)。提供对照表：
- 左主干 = LM_5
- 前降支近/中/远段 = LAD_5/6/7
- 回旋支近段 = LCX_11
- 右冠近/中/远段 = RCA_1/2/3

### Q3: 狭窄程度需要很精确吗 (如 73% vs 75%)？
**A:** 不需要！临床常用档位即可 (轻度 <50%、中度 50-70%、重度 >70%)。Benchmark 允许 ±10% 误差。

### Q4: 如果某个血管段在这个 Case 里看不清怎么办？
**A:** 标注为 "not_assessable" 或 "poor_quality"，我们的 schema 支持这个标记。不要勉强猜测。

### Q5: 需要标注 CTA 吗？
**A:** 第一个 Case (陈秀川) 只有 DSA，可以只标 DSA。后续 10-20 个病例最好有 CTA + DSA 配对 (这是 benchmark 的核心创新点)。
